# lics trove

A local node visualizer. Create and drag nodes, connect them, edit their details, and import or export a canvas. Changes are saved in your browser's local storage.

## Run on your computer

Install Node.js 20 or newer, then run:

```bash
npm start
```

Open **http://localhost:3000** in your browser. Stop the server with `Ctrl+C`.

No package installation, account, or hosted service is required. To use another port, run `PORT=4000 npm start`.
